# VOLTRA — официальный сайт

Лендинг VOLTRA в отдельной папке `voltra-landing/` существующего репозитория `Chelixxx/chelixxx-giftbot-gramsrv`. Основные файлы сервера, веб-клиента и админки не меняются.

## Отдельный проект на Layero

Создай **второй проект** в Layero и подключи тот же GitHub-репозиторий:

1. Открой `app.layero.ru` и выбери нужную организацию.
2. Нажми «Создать проект» → «Импортировать из GitHub».
3. Выбери репозиторий `Chelixxx/chelixxx-giftbot-gramsrv`.
4. Выбери ветку `voltra-landing`.
5. В настройке «Папка приложения» / Root Directory укажи `voltra-landing`.
6. Тип сайта — Static / Статический сайт; входной файл — `index.html`.
7. Запусти Deploy.

У проекта будет отдельный адрес `*.layero.app`. В этой схеме Layero обслуживает отдельную папку репозитория, не смешивая её с основным приложением. Дальнейшие обновления лендинга отправляются в ветку `voltra-landing`.

## Ссылки

В `index.html` замени:
- `YOUR_APK_LINK` — реальная ссылка на APK;
- `YOUR_WEB_LINK` — адрес веб-версии VOLTRA.

## Ежедневные промокоды

Открытый реестр находится в `promos.json` в этой же папке. В нём 100 записей на период 27.11.2026–06.03.2027, часовой пояс — `Asia/Yekaterinburg`. Лендинг загружает JSON и показывает только запись с датой текущего дня; в полночь YEKT запись меняется автоматически.

**Реестр публичный:** любой посетитель может открыть файл и увидеть все будущие коды и размеры наград. Это сделано намеренно по запросу владельца проекта. Все записи помечены `active: true`.

Для переноса всех кодов в таблицу `promos` Grammystore подготовлен файл `promos-seed.sql`. Он включает все 100 записей сразу, выставляет `active = TRUE` и `max_acts = 0`; штатный `claimPromo` использует таблицу `promo_claims`, чтобы один Telegram-пользователь мог активировать каждый конкретный код только один раз. Импортировать SQL нужно в PostgreSQL Grammystore после проверки схемы.

**Важно:** JSON — публичный источник списка, SQL — подготовка данных в PostgreSQL. GitHub сам не начисляет Stars. SQL ещё не был запущен в production-базе, а замороженный Telegram-бот сейчас не принимает команды. Чтобы начисления реально заработали, нужно подключить рабочий backend/бот к этой таблице или сделать авторизованный API-обработчик; публиковать секреты БД или GitHub-токены в клиенте нельзя.
